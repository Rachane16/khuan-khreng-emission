MODEL & DATA

วิธีคำนวณและขอบเขตผลลัพธ์

  1. แบ่งวันด้วยเวลาไทย แล้วรวม polygon ที่ซ้อนกันภายในวันและชุดดาวเทียมที่เลือก
  2. ตัด Active Fire กับเชื้อเพลิงแต่ละชั้น โดยคงการซ้อนทับระหว่างชั้น
  3. คำนวณเสม็ด surface fuel และ leaves + bark แยกกันบนพื้นที่เสม็ดเดียวกัน
  4. คำนวณดินพรุชั้น 0–10 cm เป็น scenario ตามสวิตช์ที่เลือก
EPM₂.₅ (kg) = Σ Aj × ρj × ηj × EFj

ในต้นแบบ polygon เป็นสี่เหลี่ยมประมาณใน UTM จากศูนย์กลางและค่า scan/track ของ FIRMS ไม่ใช่แนวขอบไฟที่สำรวจภาคสนาม ใช้ตามนิยามพื้นที่ของโครงการ

ผลรายวันประเมินเชื้อเพลิงตั้งต้นแยกแต่ละวัน ไม่หักพื้นที่จากวันก่อน การรวมข้ามวันจึงอาจนับเชื้อเพลิงเดิมซ้ำ ส่วน undergrowth ในเสม็ดและชั้นหญ้า/กระจูดต้องใช้ตามนิยามมวลเชื้อเพลิงของโครงการ

ผลเป็นมวลปล่อย PM₂.₅ ไม่ใช่ความเข้มข้นในอากาศ μg/m³ ข้อมูลขาดหายหรือ API ล้มเหลวจะไม่แสดงเป็นศูนย์การตรวจพบ
